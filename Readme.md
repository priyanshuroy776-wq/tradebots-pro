
# TradeBots Pro

A dark-themed educational market dashboard and paper-trading prototype.

## Features
- Market watchlist with illustrative demo prices
- EMA 12 and EMA 26 calculations
- RSI calculation
- Demo price chart
- Virtual trading balance
- Simulated buy and sell history
- Mobile-friendly interface

## Setup
Open `index.html` in a browser or publish the repository using GitHub Pages.

## Important
This is an educational simulation. Prices and chart data are illustrative, not live market data. Orders use virtual funds only. This project does not connect to brokers or exchanges and does not place real trades.
